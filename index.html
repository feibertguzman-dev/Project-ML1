Acerca del Proyecto

Esta aplicación explica de manera práctica e interactiva dos fundamentos básicos de la Introducción a la Inteligencia Artificial, permitiendo comparar el razonamiento binario con el razonamiento aproximado del ser humano.

Lógica Proposicional Clásica

Basada en el principio de bivalencia. Una proposición solo puede ser Verdadera o Falsa. Utiliza tablas de verdad para analizar conectivos lógicos.

Lógica Difusa

Permite trabajar con grados de verdad en el intervalo [0, 1]. Ideal para representar conceptos imprecisos y aproximar el razonamiento humano.

Características Principales

Aplicación web interactiva desarrollada con Streamlit con todas las funcionalidades necesarias para el aprendizaje

Tablas de Verdad Interactivas

Genera tablas de verdad para Negación (¬), Conjunción (∧), Disyunción (∨) y Bicondicional (↔) con visualización clara y comprensible.

Clasificación Difusa de Temperatura

Ejemplo práctico con sliders interactivos para observar cómo se calculan los grados de pertenencia a FRÍO, TEMPLADO y CALIENTE.

Operadores Difusos

Visualiza la aplicación de los operadores AND (min), OR (max) y NOT (complemento) con valores personalizables.

Aplicaciones en IA

Descubre aplicaciones reales de la lógica difusa en control difuso, vehículos autónomos, robótica, sistemas expertos y más.

Documentación Integrada

Pestaña con teoría completa, manual de uso, evidencias del desarrollo y archivos de documentación accesibles desde la aplicación.

Interfaz Intuitiva

Diseño limpio y responsive con navegación por pestañas, ideal para estudiantes que se inician en el mundo de la Inteligencia Artificial.

Cómo Usarlo

Fácil de instalar y ejecutar localmente

1. Clonar

git clone [repo-url]

2. Instalar

pip install -r requirements.txt

3. Ejecutar

streamlit run app.py
